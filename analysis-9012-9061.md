# Analysis notes for Wireshark MRs !9012-!9061

The batch contains 45 merged MRs, three closed MRs (!9048, !9018, !9012), and two open MRs (!9050, !9037). Merged work received the strongest weight; open and closed work was used only where the review discussion itself was durable.

- !9061 distinguishes logical packet extent from captured snapshot bytes and adopts common checksum status handling.
- !9060 moves reusable Zstandard decompression into the TVBuff layer and adds decompression edge-case coverage.
- !9059 shows review catching both static-analysis dead stores and conflicting value mappings before merge.
- !9054 promotes BPv7 endpoints into first-class address/conversation identity.
- !9035 contains high-authority review from Guy Harris and John Thacker on pcapng string termination versus generic UTF-8 repair; later !9705 remains the stronger accepted implementation.
- !9026 evolves USB endpoint dispatch with a collision-free compound key namespace while retaining legacy lookup.
- !9024, with backports !9032 and !9033, makes UTF-8 explicit where external format semantics require it; Guy Harris explicitly requested the backports.
- !9020/!9021 and !9014/!9015 reinforce bounded streaming decompression and progress based on consumed input.
- !9018 is rejected-design evidence: maintainers preferred preserving a Visual Studio environment sanity check over inventing a convenient architecture default.
- !9013 provides strong review-process evidence from focused packet captures, prolonged fuzzing, and field-registration corrections.
- !9012 is superseded by merged !9030 and therefore carries little implementation weight.

MR !9011 exists at the same corpus commit and was inspected only as the next-frontier metadata probe, not reviewed or counted.
