## Strongest promoted findings

- !8149 (Guy Harris): keep Wireshark `WTAP_ENCAP_*` numbering separate from pcap/pcapng `LINKTYPE_*` numbering.
- !8118 (Guy Harris): do not infer a dissector's transport contract from neighboring entries in `pinfo->layers`; use transport-specific entry points/registration and pass explicit context to common code.
- !8126 and !8130 (Guy Harris): distinguish dissector-handle descriptions from protocol short/long names; Decode As needs handle-level presentation metadata when one protocol has multiple selectable variants.
- !8122 (John Thacker): generic frontends should consume optional capabilities supplied through registration rather than hard-code protocol families.
- !8121 (John Thacker): strings passed directly into the protocol tree are internal UTF-8 values and must already satisfy that contract.
- !8114 and !8137 (John Thacker): respect `pinfo->can_desegment` before requesting reassembly, and mutate persistent stream/reassembly state only on the pass intended to build it.
- !8160 and !8132: choose container/key representations that match the semantic value and lifetime; direct pointer encoding is efficient for bounded nonzero scalar IDs, while explicit membership APIs are needed when a stored zero must be distinguishable from absence.
- !8153: generator changes that affect committed generated dissectors require regeneration of those consumers, not just modification of the generator.
