# Review findings for !1110-!1159

The most durable lessons concern preserving metadata across split outputs, keeping parser coordinate systems consistent, representing historical values as derived context, making one-pass analysis state available early enough, keeping expert category and severity distinct, using unknown extents until lengths are known, and separating payload representation from framing rules.

High-authority evidence came from merged changes by Guy Harris and direct review by Wireshark maintainers. The one closed MR in the batch, !1140, was used only as negative review evidence and was not treated as accepted implementation precedent.
