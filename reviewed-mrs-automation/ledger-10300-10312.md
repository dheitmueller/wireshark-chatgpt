## Review highlights

- **!10301 (Guy Harris, merged master)** gives the strongest architectural evidence in the batch. The NHRP Mandatory Part is handed to its helper as a bounded subset TVB rather than as the full packet plus a caller-managed offset/end. The helper can use local offsets and `tvb_reported_length()` as its natural boundary, reducing the chance that mandatory-part parsing leaks into extensions. The refactor also replaces derived Boolean mode flags with direct switching on the protocol discriminator, attaches extension-offset expert diagnostics to the actual offset field item, and registers value interpretation directly on the extension-type field.
- **!10305 (John Thacker, merged master)** replaces nested `dissector_try_uint()` calls with `dissector_try_uint_new(..., FALSE, NULL)` because dispatching DRDA command/parameter subdissectors should not repeatedly add the DRDA protocol name to the frame's protocol list. This is a useful dissector-table API precedent: choose the dispatch variant whose protocol-layer side effects match the logical layering.
- **!10312 (John Thacker, merged master)** reuses one `dissector_handle_t` for SQLSTT and SQLATTR because both opcodes carry the same FD:OCA SQLSTTGRP object. When multiple table keys have an identical decode contract, share the handle rather than manufacturing duplicate handles for the same parser.
- **!10302 (Pascal Quantin, merged master), reinforced by stable backports !10303 and !10304**, fixes a two-bit ISAKMP field to use `ENC_BIG_ENDIAN`. The fact that the semantic value occupies the two least-significant bits does not make the wire encoding little-endian. This strongly corroborates the notebook's existing rule to separate byte/bit encoding from semantic bit significance.
- **!10308 (Gerald Combs, merged master), reinforced by !10310 and !10311**, adds a narrowly scoped dpkg `--force-overwrite` workaround for an LLVM/Ubuntu packaging collision, with links to both upstream issue trackers, and carries the same workaround to supported release branches. Temporary dependency workarounds should state the external defect they compensate for and remain as narrow as possible.
- **!10306 and !10309** are release backports of the BFCP attribute-length correction. They reinforce the parser invariant that a protocol length field must be interpreted from the specification's exact inclusion/exclusion rules and that cursor advancement must use the same corrected payload length as the displayed field.
- **!10307** makes a CIP helper `static`, keeping file-local implementation symbols out of external linkage when no cross-translation-unit contract exists.
- **!10300 (Gerald Combs, merged master)** changes I/O Graph checkbox text to sentence case and updates the User's Guide in the same MR to document the controls. This is useful UI/documentation consistency evidence but does not justify a broader new convention beyond the project's existing presentation/documentation guidance.
